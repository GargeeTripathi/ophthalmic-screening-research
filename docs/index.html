Provenance-aware ophthalmic screening

An empirical audit of a widely used fundus benchmark, and a human-in-the-loop screening prototype built around what it found.

What this project asks

Public four-class fundus benchmarks are widely reported at 95–96% accuracy. This asks how much of that is retinal pathology and how much is where the image came from, re-evaluates standard classifiers under a corrected protocol, and builds a human-in-the-loop screening prototype around the answer.

Findings

Acquisition provenance nearly determines the label

Majority baseline 26.0%. A four-row source lookup table reaches 69.1%. A metadata-only classifier reaches 66.7% without seeing a single pixel. Within one source the signal vanishes (+0.004).

Patient leakage is real, confirmed on a deployable model

A linear head gains +0.005 (p=0.75) — it cannot memorise. A fine-tuned ResNet50 on a GPU gains +0.022 at p<0.001; a 1-NN retriever gains +0.045 at p≈0. Splitting by patient matters more as model capacity rises.

The model does not transfer across acquisition sources

Trained on ODIR, it scores below majority-class guessing on three of four unseen sources.

It is not a demographics detector

Cataract-vs-rest AUROC holds near 0.94 under age and sex matching, and age plus sex alone score below the majority baseline.

Raw OCR confidence is near-useless for clinical field extraction

AUROC 0.52 and 0.64. A learned correctness estimator reaches 0.98 and 0.99; the signal is in value format and length, not in OCR confidence.

Two negative results are reported, not tuned away

The protocol ladder's initial null, later corrected by the capacity sweep; and the learned deferral gate, which lost to two hand-written rules and was dropped by a kill rule written before the run.

The prototype

The referral document never changes the diagnosis. That is enforced in code — predict_image() does not take the document as a parameter — and the interface mirrors it: the image pathway and the document pathway are separate columns that meet only at the decision banner. The referral, and how reliably it was read, decide only whether the system answers.

Running it

The live app needs a server, because screening runs a PyTorch model:

  • pip install -r requirements.txt && pip install -e .
  • python scripts/serve.py → http://127.0.0.1:8000
  • python scripts/run_all.py rebuilds every experiment (~70 min, CPU)

The repository is self-contained: the committed model is 34 KB, and the ImageNet backbone is fetched from torchvision at runtime. ODIR images are not redistributed, so a fresh clone starts in upload-only mode.

Honest limits

  • 203 cataract and 182 glaucoma patients — intervals, not point estimates.
  • Every model sits on frozen ImageNet features; a fine-tuned backbone may differ.
  • The referral corpus is synthetic. Technical evaluation, never clinical validation.
  • Attribution shows where attribution falls, not that the model sees a lesion.
  • No prospective data, no clinical trial, no regulatory clearance.
